# Tools archive

Files from the standalone `video-ad-editor` plugin package (MIT, per its README), kept here as source material for the `reel-editor` skill. They are an archive, not wired into HyperFrames: the package's numbered scripts (`scripts/01_cut_plan.py` and the others), `engine.js`, `render.js`, `moves.js`, `motion-kit.js`, `vendor/three` and the fonts were not part of the upload, so the engine cannot run from this folder alone.

| Folder                              | Contents                                                                                                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `motion/`                           | Motion engine pieces: `ENGINE-API.md`, `audio.py`, `voice.py`, `timeline.py`, `engine.html`, `device3d.html`, font licenses, moves bank credits and picker |
| `references/`                       | Reference notes: any-environment, audio-enhance, backdrop, beat-fx, capcut, collage                                                                        |
| `sibling-skills/`                   | Instructions of the five sibling skills (thumbnail, podcast, motion, montage, davinci)                                                                     |
| `onboarding/`                       | Taste-picker page (`index.html`) the package opens on first run                                                                                            |
| `package-README.txt`                | The package README                                                                                                                                         |
| `build-release.sh`                  | The package's release builder                                                                                                                              |
| `original-video-ad-editor-SKILL.md` | The package's original skill file, unmodified (includes its own promo footer)                                                                              |
