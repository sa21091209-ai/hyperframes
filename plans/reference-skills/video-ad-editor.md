# ريل من فيديو كلام

> **حالة المستند:** مرجع تصميم لـ skill مستقبلي، مو skill منصّب. يحدد المراحل والقواعد، والتنفيذ يتم بأدوات hyperframes (الجدول تحت).

المخرَج: MP4 واحد 9:16 جاهز للنشر، ومعه ملف ترجمة `.srt` ونص الكلام `.txt`.

## أسلوب العمل مع المستخدم

- **أنت اللي تجهّز، مو هو.** لا تعطيه قائمة أوامر ينفّذها. ناقص شي؟ «ناقصني أداتين أجهّزهم لك الحين، ياخذ دقيقتين — أبدأ؟»
- **بلا مصطلحات تقنية:** «أداة ترسم الشرائح» لا «puppeteer»، «جودة الفيديو» لا «كوديك».
- **قل له وين احنا كل مرحلة وكم ياخذ:** «شلت السكتات — نصف الفيديو راح. الحين أفرّغ كلامك، 3 دقايق.»
- **شي واحد بكل مرة،** وريه لقطة أو ملخص بعد كل مرحلة مهمة.
- **عنصر واحد بالمرة:** مشهد أو تأثير جديد يتركّب لحاله، ورقة لقطات، وبعدها اللي بعده. الطلب صغير؟ عدّل الجزء المطلوب بس.
- **لا تسأله «أي وضع تبي؟»** قل بجملة شنو فهمت وكمّل.

## المراحل

### 1) استلام الفيديو

- 4K أفضل لأن الزوم ينقص من الأصل، لكن 1080p يشتغل. **لا ترفضه ولا تطلب إعادة تصوير.**
- فيديو بالعرض (مقابلة، بودكاست)؟ نفس المراحل، والقص يكون بالطول حول الوجه بدل التمطيط.

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 src.mov
```

**فريمات ساقطة:** تسجيل المتصفح أو تطبيق كاميرا مو أصلي يرمي فريمات. افحص الفجوات قبل القص:

```bash
ffprobe -v error -select_streams v -show_entries frame=pts_time -of csv=p=0 src.mov \
  | python3 -c "import sys;t=[float(x) for x in sys.stdin if x.strip()];g=[(round(a,2),round(b-a,2)) for a,b in zip(t,t[1:]) if b-a>0.07];print(len(g),'فجوة',g[:8])"
```

فيه فجوات؟ رمّم قبل القص وقل له:

```bash
ffmpeg -i src.mov -vf "minterpolate=fps=30:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1" -c:a copy src_fixed.mov
```

### 2) خطة القص

اكتشف السكتات وخطط القص. قل له كم انشال: «شلت 52 ثانية سكوت — الفيديو صار 46 بدل 98.»

### 3) تحسين الصوت (اختياري)

فيه صدى أو ضجيج، أو قال «حسّن الصوت»؟ سوّها **قبل** التفريغ حتى يسمع وِسبر صوتاً نظيفاً. احفظ الأصل، وقل له أي طريق مشيت.

### 4) التفريغ بتوقيت الكلمة

```bash
ffmpeg -v error -i src.mov -vn -ac 1 -ar 16000 -y a.wav
python3 -m whisper a.wav --language ar --model medium --word_timestamps True \
  --output_format json --output_dir . --fp16 False --verbose False > whisper.log 2>&1
```

ياخذ دقايق — شغّله بالخلفية وقل له كم يتوقع. فشل؟ `tail -5 whisper.log`.

### 5) التصحيح والكابشن

وِسبر يغلط بالعامية الخليجية، فصحّح كل جملة قبل الكابشن. اكتب `fixes.json`:

```json
{
  "fix": [
    ["كل", "شي", "تشوفه"],
    ["الكابشن", "الزوم"]
  ],
  "hot": ["تشوفه", "الزوم"]
}
```

- `hot` = كلمات تنبرز وقت نطقها.
- **عدد كلمات كل جملة بعد التصحيح = عدد كلمات وِسبر لنفس الجملة.** وإلا تختل التوقيتات.
- **لا تخترع كلام ما قاله.** ما تعرف شي؟ عمّم بدل ما تخمّن.

### 6) اعرض عليه النص وشيل اللي ما عجبه (إلزامي)

قبل تصميم أي مشهد، اطبع كلامه كامل بالشات، مرقّماً بالتوقيت، واسأله: «شنو تبي أشيل؟»

- **الجملة المعادة:** الأولى غلط والثانية التصحيح. «قلت الجملة مرتين — ‹قدرنا نحل السبب› ثم ‹قدرنا نعرف السبب›. أشيل الأولى؟»
- الحذف يزيح كل اللي بعده (القص والكابشن والمؤثرات)، فسوّه هني. الحذف بعد تصميم المشاهد يزيح أوقاتها كلها.
- بعد أي حذف: أعد القص والزوم، وأعد الرسم كاملاً.

### 7) القص والزوم

قص الفيديو حسب الخطة وطبّق الزوم.

**القص من فوق الراس (إلزامي بأي فيديو فيه كرت):**

- قصّ **ثابت طول الفيديو**، بلا تتبع ولا كاميرا تلحقه.
- يبدأ من فوق أعلى نقطة وصلها راسه بهامش صغير (1.5٪).
- لا ينقص راسه، ولا يطلع سقف فاضي. «مساحة كبيرة فوق راسه» غلط بنفس الدرجة.
- تحقق بعينك بلقطة مقرّبة.

### 8) تصميم المشاهد

اقرأ قواعد الحركة قبل أي مشهد، وصمّم من **معنى الكلام**، مو من قالب.

| اللحظة                  | التخطيط   | الشكل                                                  |
| ----------------------- | --------- | ------------------------------------------------------ |
| كلام بلا رسم            | `R_FULL`  | وجهه ملء الشاشة، أسفل الكابشن عند y 1460               |
| أي رسم أو موشن          | `R_DOWN`  | الرسم فوق (y 280-520) ← الكابشن ← وجهه تحت بعرض الشاشة |
| بي-رول أو لوحة كبيرة    | `R_LOWER` | الكرت الكبير فوق ← الكابشن ← وجهه صغير تحت             |
| شرح كامل (أرقام، قوائم) | `R_OFF`   | بلا وجه، صوته يكمّل                                    |

- **الكابشن ما ينكتب على وجه المتحدث أبداً.** بأي وضع فيه كرت فيديو، الكابشن كله فوق الكرت.
- اختيار التخطيط قرارك من المعنى: الوجه أهم ولا الرسمة؟

**المنطقة الآمنة** (أزرار انستقرام) — لا تحط نص في:

| المنطقة | الإحداثيات                                        |
| ------- | ------------------------------------------------- |
| أعلى    | y 0-150                                           |
| أسفل    | y 1620-1920 (وحزام حذر 1500-1620)                 |
| يمين    | x 950-1080 بين y 1100 و1750 (لايك، تعليق، مشاركة) |

أول كابشن يبان قبل نص ثانية.

**عاين قبل الرسم الكامل:** ورقة لقطات وحدة بـ6 لقطات (3 أعمدة × صفّين، على كل لقطة توقيتها)، واعرضها عليه.

### 9) المؤثرات الصوتية

- المؤثر بلحظة لها معنى (رقم ينزل، شي ينكسر، مشهد ينتقل)، مو رشّ على كل كلمة.
- 15 حدث بالدقيقة بالكثير، والذروة تحت -18 dBFS.
- اعرض عليه وين حطّيتها قبل التصدير.

### 10) الرسم والتجميع

ارسم الفريمات، ثم جمّع الصورة مع الصوت. الرسم يكمّل من وين وقف. عدّلت مشهد؟ أعد نافذته بس.

### 11) معايرة الصوت

ارفع الصوت إلى **-14 LUFS** والذروة **-1.5 dBTP** أو أقل. فيه ملف صوتي بالخلفية؟ ينضاف وينخفض تلقائياً وقت الكلام. الصورة تنسخ بلا إعادة ترميز.

### 12) ملف الترجمة

- `.srt` لليوتيوب ولينكدإن.
- `.txt` = نص كلامه كامل لكابشن البوست.

## القواعد الثابتة

1. **أرقام غربية دائماً** (0-9).
2. **الألوان من الثيم لا غير** — لا لون ثابت بالكود.
3. **صفر تعديل لوني على صورته:** لا تدرّج ولا صبغة ولا LUT ولا بلر، إلا بطلب صريح. الألوان للكروت والنصوص بس.
4. **آيفون HDR:** حوّله إلى SDR بتحويل ألوان صحيح (`zscale` مع `tonemap=hable`). التحويل الساذج يبهّت الصورة فيحسبها «تعديل لوني».
5. **صحّح تفريغ وِسبر** قبل الكابشن، ولا تخترع كلام.
6. **لا نشر ولا جدولة** — التسليم ملف بس.
7. **سمّها «ملف صوتي بالخلفية» لا «موسيقى».** المحتوى يحدّده هو.
8. **اخترع مشاهد جديدة كل مرة.** الأمثلة مكتبة أنماط، مو قالب.
9. **أي صورة أو تسجيل شاشة أو شعار بنسبته الأصلية:** تصغير وتكبير نسبي بس. لا ضغط ولا قصّ إلا بطلبه.
10. **القرآن حرفياً من المصدر — ولا حرف باليد:**
    - انسخه آلياً من API (`api.quran.com` ← `text_imlaei`، أو `api.alquran.cloud`).
    - قارن حروفه بمصدر ثانٍ قبل الرسم.
    - الإملائي المشكّل أوضح من العثماني. الخط العثماني: `Amiri Quran`.
    - أي كلام مو آية («قال الله تعالى»، اسم السورة) بخط الثيم العادي.
11. **الزوم آوت = رجوع من زوم إن وبس.** لا يحوّل الكادر لكرت، ولا يطلع أصغر من الأصل.
12. **الهوك فيه حركة بأول ثانية** — زوم إن سريع ناعم، أو عناصر تطلع من ورا ظهره. أول فريم ثابت = سكرول.
13. **الكلمة المنبثقة تبقى لين تخلص جملتها** (0.6 ث كحد أدنى)، مو ومضة نص ثانية.
14. **ممنوع افتراضياً** إلا لو طلبها بالاسم:
    - كتابة حرف حرف (تكسّر الحروف — حرّك كلمة كلمة).
    - توهج، ارتداد، تدرّج على النص، خلفية بنفسجي ← أزرق.
    - طلب توهج؟ على الشاشة كاملة، لأن المستطيل المحدود يطلّع حواف.
15. **متحدث أسلوبه هادي متعمّد** (قرآن، موعظة، قراءة): اسأله «أخلي السكتات مثل ما هي؟» وإذا وافق لا تقص السكتات، لأن القص هني يطلع قفزات.

## التحقق قبل التسليم (إلزامي)

1. **قبل الرسم الكامل:** لقطة من **نص كل مشهد** (مو 6 عشوائية). دوّر: نص مقصوص، تداخل، رقم مو من مصدر الحقائق، حواف القص حول الشخص.
2. **المنطقة الآمنة:** تأكد إن ولا نص داخل مناطق الأزرار، وإن أول كابشن قبل نص ثانية.
3. **المزامنة:** فرّغ الناتج وقارن بدايات الجمل بالكابشن. الفرق أقل من 0.1 ثانية.
4. **الصوت:** قرابة -14 LUFS، والذروة -1.5 dBTP أو أقل.
5. **العين:** ورقة وحدة بـ6 لقطات من الناتج النهائي، تنشاف فعلاً.
6. **الحجم:** تحت 30 ميقا.
7. **lint:** `npx hyperframes lint` ثم `npx hyperframes check` لازم يمرّون.

## التسليم

اعرض الملف مع: المدة، كم انشال من السكتات، عدد المشاهد، والعلو النهائي. سلّم معاه `.srt` و`.txt`، واذكر إنك ما نشرت شي.

**الكفر = أول فريم بالفيديو (إلزامي):**

- **المربع الآمن:** الريل 9:16 بس انستقرام يعرضه بالبروفايل 4:5 (وأحياناً 1:1). كل المهم — الوجه والكلام والشعارات — داخل مربع 1080×1080 بنص الصورة (y 420-1500). المربع وهمي: لا إطار ولا خط.
- **الكلام هوك مختصر:** سطرين، 5 كلمات بالكثير، ≈9 أحرف بالسطر، على الصدر أو تحته شوي.
- **أحجام تنقرا بالجوال:** الشبكة تصغّر الكفر لـ12٪، فالعنوان ≥ 170 بكسل، أي نص ≥ 110، الشعار ≥ 200.
- **صورة الشخص:** عنده صورة مقصوصة بخلفية شفافة؟ استخدمها على خلفية بلون خلفية الفيديو. بدونها: أوضح فريم من المصدر.
- **شعارين بقصة مقارنة** (✕ للقديم، ✓ للبديل): بس لو الفيديو «من كذا لكذا». ينحطون صف أعلى المربع والراس تحتهم.
- ركّب الكفر في أول 0.1 ث بالفيديو، وهذا ملف التسليم.
- اعرض معاينة الكفر بنسب 9:16 و4:5 و1:1 جنب بعض، وتأكد إن ولا شي مقصوص بالـ1:1.
